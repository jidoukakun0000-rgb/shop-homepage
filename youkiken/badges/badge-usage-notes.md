# メニューバッジ仕様 v2

## 文言と表示順

- 表示文言：`持帰` / `特盛可`
- 常に `メニュー名 → 名物/人気 → 特盛可 → 持帰 → 価格`
- `menu.json` の `tags` には `"特盛可"`、`"持帰"` を格納する

## 凡例

- Web：stickyヘッダー直下に常設し、メニュー末尾にも再掲する
- 紙：各ページ右上に配置する
- 大盛り説明：`麺類大盛り：平日無料・土日祝＋200円` を凡例内に明記する
- 必要に応じて、別行で `ご飯類・スープ大盛り：＋200円` を明記する

## 印刷色

| バッジ | RGB | CMYK（Japan Color 2011 Coated基準の指定値） |
|---|---|---|
| 持帰 | `#C2410C` | C0 M66 Y94 K24 |
| 特盛可 | `#7A4A18` | C0 M39 Y80 K52 |

印刷所のプロファイルに応じて最終的な色校正を行う。紙用SVGの文字はアウトライン化済み。
