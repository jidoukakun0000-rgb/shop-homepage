## 紙の書き込みの意味（判定ルール）
紙は **既存メニューの印刷** と **ボールペンの手書き** が混ざっている。

| 紙の見え方 | 判定 |
|---|---|
| 印刷の品目（品名の行）に**斜線**が引いてある（1本でも×でも） | **削除** |
| 印刷の価格が消され、**ボールペンで数字が上書き／横に書き足し**されている（品名は生きている） | **価格変更**（新価格＝手書きの数字） |
| 価格に何度も書き直しがある | **最後に残っている、消されていない数字**が新価格。どれが最後か分からなければ要確認 |
| 品名に斜線があり、価格にも書き込みがある | **削除が優先** |
| **手書きで書かれた新しい品目**で、線で消されていない | **新規追加**（価格は手書きの数字） |
| **手書きの新品目案が線で消されている** | **採用しない**（追加しない）。店主は案を書いてから消して絞り込んでいる |
| 手書きの品目は生きていて、手書きの価格だけ消されて別の数字がある | 新規追加。価格は最後に残った数字 |
| 何も書き込みがない | **継続**（変更なし） |
| 矢印・丸囲み・「？」・メモ書きなど上に当てはまらない印 | **要確認**（勝手に解釈しない） |

## 間違えないための手順（この順に必ずやる）

### 1. 写真の確認
- ぼやけ・影・斜め・見切れで読めない部分があれば、**先に撮り直しを頼む**。読めない写真のまま進めない
- 各写真が「平日／土日祝」「どの面・どのカテゴリ」かを特定する。紙に書いていなければ、品目と価格から menu.json と照合して推定し、推定したことを明記する

### 2. 全行の書き起こし（変更行だけでなく全部）
紙の**すべての行**を、写真ごと・カテゴリごとに表に起こす。変更のない行も含める（抜けを見つけるため）。

| 写真 | 平日/土日祝 | カテゴリ | 印刷の品名 | 印刷の価格 | 書き込みの種類 | 手書きの内容 | 判定 | 新価格 | 確信度（高/中/低） |

- **行数の照合**：カテゴリごとに「紙で数えた行数」と「書き起こした行数」が一致すること。一致しなければやり直す
- **menu.json との照合**：印刷の品名を menu.json の品目に対応づける。表記ゆれ（ギョーザ/餃子、カタカナ/ひらがな、全角/半角、（）の有無）は同一とみなしてよいが、**対応づけられない品目は勝手に新規扱いにせず「要確認」**
- menu.json にあって紙に無い品目、紙にあって menu.json に無い印刷品目も一覧にして報告する（紙が古い版の可能性がある）

### 3. 二重読み取り（独立した2回目）
- **Agent ツールでサブエージェントを1つ起動し、1回目の結果を見せずに、同じ写真から同じ表を独立に作らせる**
- 2つの表を突き合わせ、**食い違った行はすべて**写真の該当部分を拡大（PILで切り出して等倍以上）して読み直す
- 読み直しても決まらない行は「要確認」

### 4. おかしな値の自動チェック（該当したら要確認に回す）
- 新価格が10円単位でない
- 値下げになっている（書き間違いの可能性）／30%以上の値上げ
- 同じ品目で平日と土日祝の判定が食い違う（片方だけ削除・片方だけ値上げ など）
- 手書きの新規品目がどちらの日（平日／土日祝／両方）に入るのか紙から読み取れない
- 新規品目がどのカテゴリに入るのか、書いてある位置から判断できない
- 新規品目の名前が既存品目とほぼ同じ（重複の疑い）
- 数字の読み違えやすい字（1と7、0と6、4と9、3と8）が含まれ、確信度が高でない

### 5. 確認シートを作って私に見せる（ここで一旦止まる）
**私が紙を見返さなくても確認できる形にすること。** PNGで出す（PDFは開けないことがある）。

- 変更がある行（削除・価格変更・新規追加・不採用・要確認）ごとに、**写真の該当部分の切り出し画像**と**判定**を横に並べる。切り出しは、作ったあと自分で画像を見て、その行が確かに写っているか確認してから並べる
- 並び順：①要確認 ②削除 ③価格変更 ④新規追加 ⑤不採用（消された新規案）
- **要確認は、店主にそのまま聞ける質問文**を付ける（例：「塩ラーメンの価格は 750円 と 780円 のどちらですか」）
- 冒頭に件数の集計（削除◯件・価格変更◯件・新規◯件・不採用◯件・要確認◯件・継続◯件）
- 書き起こし表と判定の根拠は `youkiken/print/menu-change/<日付>/` に Markdown と JSON で保存し、コミットして記録に残す

**ここで私のOKと要確認への回答が出るまで、menu.json もメニュー表も一切変更しないこと。**
