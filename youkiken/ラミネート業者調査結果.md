## 3. 推奨用紙

店主のご要望「厚紙がよい。ただし厚すぎるのはダメで、画用紙よりは薄いくらい」に対して：

| 用紙 | 坪量 | 厚さ目安 | 評価 |
|---|---|---|---|
| コピー用紙 | 約64 g/m² | 0.09mm | 薄すぎ |
| **コート135kg（四六判）** | **約157 g/m²** | **約0.15mm** | **◎ ど真ん中。これを推奨** |
| コート165kg | 約192 g/m² | 約0.18mm | ○ 画用紙にかなり近い |
| アートポスト180kg／コート180kg | 約209 g/m² | 約0.22mm | △ ほぼ画用紙と同等＝「厚すぎ」の域 |
| 画用紙 | 200〜240 g/m² | – | 店主が「厚すぎ」とした基準 |

### 結論：**コート135kg（約157g/m²）**

- ラミネート100μを両面に貼ると **+0.2mm** されるので、仕上がりは **0.15 + 0.2 = 約0.35mm**。これは画用紙単体（約0.25mm）より厚く、十分な「腰」が出ます。
- ここでアートポスト180kgを選ぶと仕上がり約0.43mmになり、店主の言う「厚すぎ」に確実に該当します。
- **紙の厚みで腰を出すのではなく、ラミネートで腰を出す**のが正解です。
- なお、パウチ加工すると紙の表面の質感は完全に隠れるため、高い紙を選ぶ意味は薄いです（グラフィックのように用紙が全部同額なら180kgでもよいですが、今回は厚みの観点から135kg推奨）。

### 表面仕上げ
- **グロス（つや有り）**：発色が良く、水拭きしやすい。標準。安い。
- **マット（つや消し）**：照明の映り込みが減って読みやすいが、+約570円/10部。指紋が目立ちやすい面も。
- 飲食店の卓上メニューなら、**グロス**で十分（プリントネットで選ぶならグロス・フチあり・角丸）。

**懸念点**：口コミサイト（みん評、評価2.75）では、返金対応の遅さやカスタマー対応への不満が散見されます。品質そのものへの致命的なクレームは目立ちませんが、**トラブル時の対応には期待しないほうが安全**です。裏を返せば、データさえ完全なら問題は起きにくいということです。

### 対抗：**グラフィック** — 品質と対応を優先するなら

## 5. 入稿前に準備すべきこと（チェックリスト）

### データ仕様
- [ ] **カラーモードをCMYKに変換**（RGBのままだと色が沈む。特に鮮やかな赤・青が変わる）
- [ ] **画像解像度は実寸で350dpi**（Web用画像の流用は不可）
- [ ] **塗り足し（裁ち落とし）を天地左右3mm**つける。背景色・写真は塗り足しの端まで伸ばす
- [ ] **切れてはいけない文字は仕上がり線から3mm以上内側**に配置
- [ ] **フォントはすべてアウトライン化**（またはPDF埋め込み）
- [ ] **トンボ（トリムマーク）をつける**（PDF書き出し時に「トンボ」「裁ち落とし3mm」にチェック）
- [ ] 書き出し形式は **PDF/X-1a:2001（日本）** または **PDF/X-4:2008（日本）**。AI（.ai）・PSD入稿も可
- [ ] **各社の専用テンプレートを必ずダウンロードして使用**（プリントネット・キングプリンターズ・アドプリントいずれも無料配布）

### パウチ加工特有の注意
- [ ] **「フチあり」を選ぶ場合、仕上がりは定型サイズより3〜5mm大きくなる**。卓上ホルダーに入れる予定なら実寸を確認
- [ ] **角が丸く加工される**（フチありでR3〜R5、フチなしでR6程度）。四隅ギリギリに文字やロゴを置かない
- [ ] 「フチなし」は断裁面から水が入る可能性があるため、**飲食店の卓上用途では「フチあり」推奨**
- [ ] スジ入れ（折り目）を入れる場合はオプションで最大2本まで。今回は平面なので不要

### 発注時
- [ ] **平日用・土日祝用は別ファイル・別注文**として入稿（2件分の注文になる）
- [ ] 表面・裏面の**天地（上下の向き）**を明示。裏面が逆さになる事故が最も多い
- [ ] **支払いはクレジットカードで即時決済**。銀行振込・代引きは入金確認待ちで受付完了が遅れ、納期が1日ずれます
- [ ] 誤字チェックは印刷前に必ず複数人で。ラミネート後は修正不可能で刷り直しになります

### データチェック体制
- プリントネット：無料の自動データチェック（フォント・色設定・解像度）＋オペレーター確認あり。**不備があれば連絡が来て、修正・再入稿の分だけ納期が後ろにずれます**

## 6. 注意点・リスク

### 納期リスク（最大）
1. **シルバーウィークで実質3営業日しかない**。9/24〜25入稿だと1〜2営業日の特急納期一択で、料金が約1.15〜1.4倍になります。
2. **連休明けは印刷各社が混雑**します。表示上の納期どおりに出荷されない可能性を織り込んでください。
3. **データ不備で1回差し戻されると即アウト**。9/24入稿・2営業日プランで組んだ場合、再入稿の余地はゼロです。
4. 配送遅延（交通事情・天候）で1日ずれる可能性もあります。**9/29必着なら、9/28着を狙う日程を組むべき**です。

### → 推奨アクション
**入稿を9/16(水)〜9/17(木)に前倒ししてください。** そうすれば：
- プリントネット4営業日（B4 8,360円 / A3 8,540円）で9/25頃には手元に届きます
- 万一の差し戻しにも連休前に対応できます
- 特急料金（+1,200〜3,000円）を払わずに済みます

前倒しが難しい場合は、**プリントネットの2営業日（9/24入稿）または1営業日（9/25入稿）**を最初から選び、9/29着を確保してください（B4で9,520〜11,380円）。

### 追加費用が発生しうるポイント
- **特急納期への切り替え**：プリントネットで4営業日→1営業日にすると1部あたり+1,500円前後
- **マット加工**：+約570円/10部
- **アートポスト180kgへの変更**：+約190円/10部
- **グラフィックの分納**：2箇所以上に送ると1箇所につき+1,500円（今回は1箇所なので不要）
- **アドプリントの中継料**：離島等のみ。群馬県は送料500円のみ
- **アクセアで用紙持ち込みをした場合の加工手数料**（キンコーズは2,640円/オーダー）。データ入稿なら不要

### 品質面のリスク
- パウチ加工すると**紙の質感は完全に隠れます**。高級紙を選んでも見た目は変わらないので、コスト増は無意味です
- **グロスは照明の映り込みが強い**。店内の照明が明るい場合、マット加工のほうが読みやすいことがあります（+570円/10部）
- ラミネートの気泡・シワは加工不良として再製作対象になりますが、**再製作には当然その分の日数がかかります**

# 【追記2】B3（364×515mm）という選択肢について

## 結論：あるが、B3から一気に価格が跳ね上がる

**理由**：一般的なオンデマンド（トナー）印刷機の最大用紙はSRA3（320×450mm）程度。**B3（364×515mm）はこれを超えるため、オンデマンド印刷では刷れず、すべてオフセット印刷（版が必要）になります。** そのため少部数では版代が価格に乗り、A3の3倍前後になります。

## 納期は絶望的

グラフィックのB3は**5日／8日納期＋部数による追加納期2〜4日**。9/24〜25入稿では9/29着は**不可能**です。B3でいくなら**9/15〜17頃までの入稿が必須**になります。

## サイズ感の注意

B3＝364×515mm は **A3の約1.5倍、B4の約2倍**の面積。町中華の4人卓に置くと、テーブルの半分近くを占めます。

- **卓上メニュー**として使うなら B4 または A3
- **壁貼り・レジ横のグランドメニュー**として1枚だけ作るなら B3も妥当

「卓上はB4×2種、壁用にB3を1枚」という使い分けのほうが、コスト・使い勝手ともに現実的です。

## B3のサンプルを1枚だけ取りたい場合

- **アドプリント PP加工**：B3マットコート180kg 両面4色 **1枚 3,970円**（1枚から注文可）。ただし5営業日＋海外工場出荷＋9/24〜25の製作休止があるため、**今週中は不可**。
- **アクセア前橋店**：B3ラミネート616円/枚で加工は可能。ただし印刷は大判インクジェット（厚手マット紙・光沢紙など）になり、**コート135kgやアートポスト180kgでは出せません**。紙質の比較サンプルとしては条件が変わってしまう点に注意。要問い合わせ。

※ PP加工はパウチ（ラミネート）とは別物です。紙に薄いフィルムを圧着する方式で、透明なフチが出ず紙の実寸で仕上がりますが、**断裁面から水が入るためパウチより耐水性は劣ります**。
