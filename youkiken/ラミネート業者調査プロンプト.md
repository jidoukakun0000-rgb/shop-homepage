飲食店のメニュー表を印刷＋ラミネート加工してくれる業者を調査して、候補を複数挙げて比較してください。実際にウェブで各社のサイトを調べ、料金・仕様・納期を確認したうえで回答してください。

## 案件の概要

群馬県高崎市の町中華「陽気軒」のメニュー表を改訂します。デザイン（版下）はこちらで作成済みの状態で入稿し、**印刷とラミネート加工を業者に依頼**します。

## 発注仕様

| 項目 | 内容 |
|---|---|
| 用紙サイズ | **A3（297×420mm）または B4（257×364mm）**。どちらでも可なので両方の料金を調べて比較したい |
| 印刷 | **両面フルカラー** |
| 種類 | **2種類**（「平日用」と「土日祝用」でデザインが異なる） |
| 部数 | **各10枚ずつ、合計20枚** |
| 加工 | **ラミネート（パウチ）加工あり**。飲食店の卓上メニューとして客が毎日手に取る用途 |
| 納品希望 | 2026年9月29日までに手元に届くこと（データ入稿は9月24〜25日を想定） |
| 納品先 | 群馬県高崎市（送料も含めて計算したい） |

## 用紙の希望

店主の要望は「**厚紙がよい。ただし厚すぎるのはダメで、画用紙よりは薄いくらい**」です。

- 画用紙は約200〜240g/m² 相当なので、それより薄く、かつコピー用紙（約64g/m²）よりはしっかりした厚みを想定
- 具体的にどの用紙・どの厚さ（連量／坪量 g/m²）が該当するか、各社の選択肢の中から**具体的な用紙名と厚さを提案**してください
- ラミネート加工をすると全体の厚みと硬さが増す点も踏まえて、適切な厚さを推奨してください

## 調査してほしいこと

1. **業者の候補を3〜5社**挙げる（ネット印刷会社、ラミネート加工専門業者、キンコーズ等の店舗型サービスなど、タイプの異なるものを混ぜてください）
2. 各社について以下を調べる：
   - **料金**：上記仕様（A3両面カラー10枚＋B4両面カラー10枚 等）での概算総額。A3の場合とB4の場合を分けて計算。**送料・データチェック料などを含めた総額**を出すこと
   - **20枚という少部数に対応しているか**（ネット印刷は最低ロットが大きい／少部数だと割高になる場合があるので要確認）
   - **2種類のデザインを同時に発注する場合の扱い**（デザインごとに版代や別注文扱いになるか）
   - **ラミネートの仕様**：フィルムの厚さ（100μm／150μm等）、つや有り（グロス）／つや消し（マット）の選択可否、角丸加工の可否
   - **納期**：データ入稿から発送・到着までの日数。9/24〜25入稿で9/29着が可能か
   - **入稿方法（デザインの受け渡し方法）**：対応ファイル形式（PDF／AI／PSD等）、色モード（CMYK指定の要否）、解像度、塗り足し（裁ち落とし）の必要幅、トンボの要否、アップロード方法（ウェブ入稿／メール／ストレージ）、テンプレートの配布有無
   - **データ不備時のチェック体制**（オペレーターチェックの有無、再入稿の可否と納期への影響）
3. **品質面の評判**を調べる（利用者のレビュー、仕上がりの評価、トラブル事例など。分かる範囲で）

## 出力してほしい形式

1. **比較表**：各社×（料金A3／料金B4／納期／ラミネート仕様／入稿形式／少部数対応可否）
2. **総額の試算**：本命2〜3社について、A3の場合とB4の場合の実際の合計金額（送料込み）
3. **推奨用紙**：店主の希望（厚紙だが画用紙より薄い）に合う具体的な用紙名と厚さ
4. **おすすめ業者とその理由**：納期のリスク、品質、価格のバランスで判断
5. **入稿前に準備すべきこと**：ファイル形式・塗り足し・CMYK変換など、デザイン側でやっておくべき作業のチェックリスト
6. **注意点・リスク**：納期が間に合わないケース、追加費用が発生しうるポイント

## 補足

- 価格は変動するため、**調べた時点の情報であること**と**出典URL**を明記してください
- 不確かな情報は推測で埋めず、「各社に要問い合わせ」と書いてください
- 今日は2026年9月8日です。納期まで日数が少ないため、**納期の確実性を重視**して評価してください
